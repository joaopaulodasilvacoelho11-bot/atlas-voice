// MÓDULO D1 — ABSTRAÇÃO DE IA
motor_ia.py — Camada de Abstração
Atlas e Lyra nunca chamam Claude diretamente. Chamam motor_ia() — que decide qual provedor usar. Um único arquivo protege todo o sistema contra corte de API.
  • Criar pipeline/motor_ia.py com função central responder()
  • Provedor primário: Claude Haiku — já em uso
  • Provedor fallback: configurado mas em standby
  • Se primário falha → fallback assume automaticamente, sem o sistema parar
  • Atlas e Lyra refatorados para chamar motor_ia() — não a API diretamente
🔐

  • Nenhum dado de conversa enviado a analytics externos

// MÓDULO D1 EXPANDIDO — MULTI-PROVEDOR
Fallback Ativo com Segundo Provedor Real
No V2 o fallback deixa de ser standby e entra em produção real. O sistema alterna automaticamente entre provedores conforme disponibilidade e custo.
  • Segundo provedor ativo — OpenAI GPT-4o mini ou Groq
  • Lógica de seleção: tenta Claude → se falha ou lento → usa fallback
  • Log de uso por provedor — JP sabe quanto cada um custa por mês
  • Configuração via config.py — trocar provedor sem mexer no código
📡
// MÓDULO D2 INÍCIO — MODO ESSENCIAL OFFLINE
Atlas Essencial — Funciona Sem Internet
Funções críticas do Atlas não podem depender de internet. Alarmes, lembretes e respostas básicas funcionam mesmo offline.
  • Alarmes e lembretes 100% locais — nunca dependem de API
  • Respostas padrão offline — Atlas avisa que está sem conexão mas continua operando
  • Whisper local — transcrição de voz sem enviar áudio para nenhum servidor
  • Modo offline declarado no dashboard — usuário sabe o status
🔍
// MÓDULO — BUSCA WEB SEGURA
Integração de Busca com Controle de Fonte
Quando o Atlas busca informações na web, ele filtra e controla de onde vêm os dados — sem expor o usuário a fontes não confiáveis.
  • API de busca com fallback — se uma fonte falha, usa outra
  • Resultados sempre processados pela IA antes de chegarem ao usuário
  • Nenhuma busca revela dados pessoais do usuário para serviços externos

// MÓDULO D2 COMPLETO — IA LOCAL NO DISPOSITIVO
Modelo de IA Rodando no Android
Um modelo leve de IA roda diretamente no celular. Sem internet, sem servidor, sem depender de ninguém. Isso é a independência real no mobile.
  • Modelo quantizado — Llama 3 8B ou Mistral 7B otimizado para Android
  • Whisper tiny/base rodando local — transcrição offline no celular
  • TTS local — voz básica mesmo sem ElevenLabs
  • Hierarquia: IA local → API Claude → fallback OpenAI
🛡️
// MÓDULO — SEGURANÇA MOBILE
Proteção do App no Android
O app Atlas no celular precisa de camadas específicas de proteção — contra acesso indevido e contra remoção forçada.
  • Ativação por voz com autenticação — só o usuário cadastrado ativa o Atlas
  • Dados criptografados no dispositivo — sem acesso por outros apps
  • Permissões mínimas — Atlas pede só o que realmente precisa
  • Backup automático local — dados nunca perdidos por falha do app
